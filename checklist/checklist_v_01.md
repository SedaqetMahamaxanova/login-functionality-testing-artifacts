# ✅ Login Functionality Checklist

- [ ] Login page is accessible via correct URL  
- [ ] Login page loads without errors  
- [ ] Username field is present  
- [ ] Password field is present  
- [ ] "Login" button is present  
- [ ] "Remember me" checkbox is present  
- [ ] User can enter a valid username  
- [ ] User can enter a valid password  
- [ ] User cannot login with empty username  
- [ ] User cannot login with empty password  
- [ ] User cannot login with invalid username/password  
- [ ] User sees error message for invalid credentials  
- [ ] Successful login redirects user to the Home page  
- [ ] "Remember me" checked → username remembered for next login  
- [ ] "Remember me" unchecked → username not remembered  
- [ ] Login session expires after inactivity (if applicable)  
- [ ] User can logout successfully  
- [ ] After logout, going back with browser back button does not reopen session
